# AI Hand Rehabilitation System

A gesture-controlled physiotherapy application built with **Python**, **MediaPipe**, and **Pygame**. This project is designed for patients recovering from hand injuries, providing a "Zero Keyboard" experience to perform rehabilitation exercises through interactive games.

## 🚀 Features
- **Zero Keyboard Navigation**: Navigate menus and start games using only hand gestures (Hover-to-Select).
- **Real-time Feedback**: Mirrored webcam feed with MediaPipe landmarks for visual guidance.
- **Progress Tracking**: Monitors flexion angles and session scores to track recovery.
- **Level-Based Progression**:
  - **Level 1 (Warm Up)**: Range of motion exercises (Balloons).
  - **Level 2 (Coordination)**: Precision movement and catching.
  - **Level 3 (Fine Motor)**: Advanced transitions between "Fist" and "Open" gestures.

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **Computer Vision**: MediaPipe
- **Graphics & UI**: Pygame, OpenCV
- **Data**: Threaded asynchronous processing for 60 FPS performance.

## 📦 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/VaradScript/AI-Hand-Rehabilitation-System.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the main application:
   ```bash
   python final_physio_game.py
   ```
